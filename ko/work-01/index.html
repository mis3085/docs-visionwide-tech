첨단 금형 가공 적용 사례 및 사례 연구
#

Vision Wide는 다양한 산업 분야의 금형 제조에 맞춘 고정밀 가공 솔루션을 폭넓게 제공합니다. 아래는 실제 적용 사례를 체계적으로 정리한 것으로, 가공 공정, 재료 및 당사 기술로 달성한 결과를 강조합니다.

자동차 라이트 금형
#

  • 모델: ASM
  • 재료: 2311 다이 스틸
  • 크기: L360 x W160 x H360mm
  • 가공 효율 향상을 위한 다중 경사면 및 사선 절단을 포함한 선형 투영 절단.
  • 표면 거칠기: Ra 0.4µm
  • 윤곽 정밀도: 0.04mm

헤드라이트 금형
#

  • 모델: SE / GS / GSF
  • 재료: P20 다이 스틸
  • 크기: L800 x W550 x H250mm
  • 0.2G 고가속 금형 마무리.
  • D25 고이송 러프 가공: F10,000 mm/min.
  • D10R5 고속 표면 마무리: S12,000 rpm, F4,000 mm/min.
  • 표면 거칠기: Ra 0.4μm
  • 윤곽 정밀도: 0.04 mm

범퍼 금형
#

  • 모델: SF
  • 재료: FC300
  • 크기: L1,000 x W400 x H350mm
  • 긴 스핀들 노즈로 공구 강성 향상 및 절삭 진동 감소.
  • D20R10 볼 엔드 공구 왕복 투영 가공, 피치 0.5mm.
  • 스핀들 속도: 12,000 rpm
  • 이송 속도: 5,000 mm/min

자동차 반사경 라이트 코어
#

  • 모델: SE/GS 시리즈
  • 재료: NAK80 다이 스틸
  • 크기: 160 x 160 x 100 mm
  • 표면 거칠기: Ra 0.4μm
  • 윤곽 정밀도: 0.02 mm
  • D3R1.5 볼 엔드 가공
  • 스핀들 속도: 12,000 rpm
  • 이송 속도: 1,500 mm/min

헤드라이트 캐비티 마무리
#

  • 재료: 합금강
  • 크기: L151mm x W105mm x H155mm
  • 표면 높이 차이: 103mm
  • 표면 거칠기: Ra 0.8 mm
  • 긴 공구 가공 (공구 길이 262mm)
  • 공구: D12R6 경질 볼 엔드
  • 공구 경로: 지그재그 윤곽 가공
  • 스핀들 속도: 8,000 rpm
  • 이송 속도: 2,000mm/min
  • 총 가공 시간: 1시간 58분

마스크 코어 금형
#

  • 모델: F 시리즈
  • 재료: S45C
  • 크기: 300 x 200 x 100 mm
  • 고속 및 고정밀 금형 가공
  • 높은 윤곽 정밀도: 98.5% 포인트 오차 < 0.02mm, 85.8% 포인트 오차 < 0.012mm
  • D12R6 볼 엔드 공구, 45° 투영 지그재그 절단
  • 스핀들 속도: 10,000 rpm
  • 이송 속도: 4,000 mm/min

벤츠 금형
#

  • 재료: NAK 80 다이 스틸
  • 0.2G 고가속 금형 가공
  • 고이송 러프 가공: D25, F10,000mm/min
  • 고속 표면 마무리 가공: F4,000mm/min
  • 표면 거칠기: Ra 0.4μm
  • 45° 투영 지그재그 절단
  • 스핀들 속도: 12,000 rpm
  • 이송 속도: 4,000 mm/min

범퍼 금형 (대형)
#

  • 모델: FA
  • 재료: FC300
  • 크기: 900 x 2300 x 930mm
  • 5축 동기 가공, 효율 30% 향상
  • 긴 스핀들 노즈로 강성 향상 및 진동 감소
  • D20R10 볼 엔드 공구, 투영 지그재그 절단
  • 스핀들 속도: 8,000 rpm
  • 이송 속도: 5,000 mm/min

자동차 판금 금형
#

  • 모델: FA
  • 재료: FC300
  • 크기: 2300 x 1600 x 250mm
  • 0.2G 고가속 금형 가공
  • 고이송 다이 표면 마무리: F7,000mm/min
  • 고명확 가공 경로
  • 총 마무리 시간: 6.3시간
  • D25 볼 엔드 공구, 45° 투영 지그재그 절단
  • 스핀들 속도: 8,000 rpm
  • 이송 속도: 7,000 mm/min

엔진 후드 금형
#

  • 재료: FC300
  • 크기: 2,000 x 1,600 x 500mm
  • 10 m/min 고속 가공
  • 0.3G 고가속 가공
  • 총 마무리 시간: 5.2 시간
  • D25 볼 엔드 공구, 피치 0.5mm, 주변 등축 가공
  • 스핀들 속도: 12,000rpm
  • 이송 속도: 5,000 mm/min

금형 검증 가공품
#

  • 모델: GS/ SE
  • 재료: 2311
  • 크기: 150 x 60 x 30 mm
  • D4R2 볼 엔드 공구 마무리
  • 공구 자국 없는 주변 보간 밀링
  • 날카로운 모서리와 코너를 가진 정밀 Z-역방향 절단
  • 표면 거칠기: Ra 0.8µm

자동차 스탬핑 금형
#

  • 재료: P20
  • 크기: L640mm x W505mm x H270mm
  • 마무리 공구: D16R8 볼 엔드, 마무리 피치 0.3mm
  • 공구 경로: 45° 투영 지그재그 절단
  • 고이송 마무리: F3000→F5000
  • 고가속 절삭: 0.05G→0.2G
  • 총 마무리 시간 20% 단축: 6시간 08분→4시간 54분
  • 표면 거칠기: Ra 0.6μm
  • 스핀들 속도: 15,000 rpm
  • 이송 속도: 5,000mm/min

  • 모델: SE / GS
  • 재료: S45C
  • 크기: 800 x 500 x 250mm
  • Vc 220 m/min, 10 m/min 고이송 가공
  • 보링 위치 정밀도: 0.006 mm (피치 400x700mm)
  • 스핀들 속도: 2,000rpm
  • D40 R1 고이송 공구

  • 재료: FC30
  • 크기: 2,000 x 1,000 x 200mm
  • 보링 홀 고위치 정밀도 1.8x0.8 m: 0.02mm
  • D900 원형 보간 가공, 원형도: 0.02mm
  • 400x400mm 직각도: 0.01mm

딥 캐비티 금형
#

  • 모델: SM
  • 재료: P20 다이 스틸

  • 4사분면 교류, 챠터 마크 없음
  • 고마무리 유지 동시 가공, 오버컷 및 챠터 마크 없음
  • 평면 정밀도: -0.011 ~ 0.006mm
  • 구면 정밀도: -0.012 ~ 0.006mm
  • D20R1 엔드밀 마무리
  • 스핀들 속도: 3,500rpm
  • 이송 속도: 5,200mm/min

  • 크기: 660 x 600 x 260mm

  • D25 고이송 러프 절단: F10,000
  • F3,000 R6 마무리
  • 다축 투영 가공
  • 스핀들 속도: 15,000 rpm
  • 이송 속도: 4,000 mm/min

볼 형태
#

  • 모델: FA / GSF
  • 재료: Al6061

  • 고동기 이송 속도: F2,000
  • 고서보 제어, 각 축 이송 > F10,000mm/min
  • 마무리 시간: <20분
  • 표면 정밀도: <±0.02mm

타이어 금형 (세그먼트 타입)
#

  • 재료: P20 다이 스틸
  • 크기: L310 x W131 x H95mm

  • 고이송 러프 가공: F7,200mm/min, Ap0.6mm
  • 고속 금형 가공: Ra<0.5μm
  • 5축 동기 R0.5mm 가공으로 공구 길이 효과적 단축 및 간섭 방지.
